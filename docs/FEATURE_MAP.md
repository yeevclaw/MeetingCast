# MeetingCast 功能地圖
用途：從使用者看得到的功能，快速找到實作入口與相關測試；以下以目前程式碼為準。
架構：Tauri 2，React 19／TypeScript 前端、Rust 後端 `src-tauri`、Python sidecar `python-sidecar` ＋ `prototype`；只收講者麥克風，不收系統音訊。
維護：改功能時同步更新本檔；路徑均以 repo 根目錄為基準，command 統一在 `src-tauri/src/lib.rs` 註冊。
CI 由 `.github/workflows/pr-checks.yml` 執行 `scripts/review-checks/feature-map.mjs`，檢查本檔列出的路徑都存在。

## 「改 X 要看哪裡」快速索引

1. **新增語言**：先讀 `docs/ADD_LANGUAGE.md`，改 `shared/languages.json`；核對 `src/lib/languages.ts`、`src-tauri/src/languages.rs`、`prototype/stt/lang_resources.py`，書寫系統判定需同步 `src-tauri/src/verify.rs` 與 `prototype/eval/checks.py`，評估案例在 `prototype/eval/golden/translation_cases.jsonl`。
2. **改版本號**：以 `tests/frontend/version-consistency.test.mjs` 為準，同步 `package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 的 meetingcast 項目；不要把目前版號寫死在本檔。
3. **改首次設定／啟動卡住提示**：看 `src/components/WelcomeWizard.tsx`、`src/components/PrewarmChecklist.tsx`、`src/components/StartupProgress.tsx`；實際預熱與模型載入對照 `src-tauri/src/sidecar.rs`、`python-sidecar/stt_engine.py`。
4. **改本場設定／預設值**：畫面在 `src/components/SessionSetupCard.tsx`、`src/windows/ControlWindow.tsx`，收合狀態在 `src/lib/sessionPanel.ts`；持久化與合法值修正在 `src-tauri/src/config.rs`；帳號與進階設定另看 `src/components/SettingsModal.tsx`。
5. **改收音／辨識漏字、斷句**：沿 `prototype/audio_capture.py` → `prototype/audio_pump.py` → `prototype/stt/local.py` 或 `prototype/stt/openai_realtime.py`；雲端參數在 `prototype/stt/openai_transcription_config.py`，stdio 邊界看 `python-sidecar/stt_engine.py`、`src-tauri/src/sidecar.rs`。
6. **改翻譯品質／延遲／重複譯文**：逐句看 `src-tauri/src/translator.rs` 與 `src-tauri/prompts/translate_system.txt`；incremental 看 `src-tauri/src/interp.rs` 與 `src-tauri/prompts/interpret_system.txt`；模式設計見 `docs/PLAN_INCREMENTAL_INTERP.md`。
7. **改譯文畫面／外觀**：看 `src/windows/TranslationWindow.tsx`、`src/App.css`；視窗重開看 `src/lib/windows.ts`，初始幾何與權限看 `src-tauri/tauri.conf.json`、`src-tauri/capabilities/default.json`。
8. **改術語／中文正規化**：看 `src/components/GlossaryModal.tsx`、`src-tauri/src/config.rs`、`src-tauri/src/text.rs`；再核對 `src-tauri/src/sidecar.rs`、`src-tauri/src/translator.rs`、`src-tauri/src/interp.rs` 的呼叫邊界。
9. **改歷史紀錄／匯出／總結**：從 `src/components/HistoryModal.tsx` 找 command，存檔與 Finder 在 `src-tauri/src/session.rs`，總結提示與串流在 `src-tauri/src/translator.rs`；停止後自動總結入口在 `src/windows/ControlWindow.tsx`。
10. **查離線／錯誤／發佈後無法收音**：先看 `src/lib/errors.ts`、`src-tauri/src/netcheck.rs`、`src-tauri/src/errors.rs`、`src-tauri/src/traces.rs`；安裝包問題核對 `scripts/build-sidecar.sh`、`scripts/postbuild-sign.sh`、`src-tauri/Entitlements.plist`。Mac 安裝與實際麥克風仍須實機驗證。

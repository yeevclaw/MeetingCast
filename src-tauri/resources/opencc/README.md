# OpenCC 字典來源

`STCharacters.txt` 與 `STPhrases.txt` 原樣取自本專案已鎖定的 `ferrous-opencc 0.4.0` 套件
`assets/dictionaries/` 下的同名檔案（上游 OpenCC，Apache-2.0；授權見 `LICENSE`）。
這兩份來源副本使用 **CRLF** 換行，請保留上游原始內容；解析時需正確處理 `\r\n`。
`STCharacters.txt` 保留供來源比對，不再用來推導共用字集合。
`STPhrases.txt` 以 `include_str!` 嵌入，用於辨認詞組命中的範圍；
也涵蓋「在后／后台」這類重疊詞組，避免將「後臺」中的「臺」誤還原成「台」。
實際轉換結果仍由套件內嵌的 s2tw 字典產生，不自行維護轉換對照表。
更新 ferrous-opencc 時應同步檢查此字典與繁體化回歸測試。

`text.rs` 僅對明列的八字「台、干、范、余、准、里、后、面」保留單字預設轉換前的字形。
若上下文轉換結果與單字轉換結果不同，或該字位於已命中的詞組內，優先採用 s2tw 結果；
後者不可省略：「然后」與「准备」的詞組結果恰好與單字預設相同，仍應轉成「然後」與「準備」。
例如「现在台灣的软件」→「現在台灣的軟件」，「后台」→「後臺」，「准备」→「準備」。
既有繁體名稱與合法詞形（程式中明列的「台灣、台北、台中、台積電、干擾、范先生、余老師、准許、里長」）
在結果等同單字預設時仍保留原字，避免「在台」等詞組片段跨入名稱而改動字形。
不改「軟件」等用語；術語表正式名稱則由 `Normalizer` 另外保護。
